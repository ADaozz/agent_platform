# 网页端

Deep Agent 的统一控制台：登录进入后，在同一界面完成对话、审批、文件与文档预览。

## 你在界面里会看到

**登录**  
账号密码、客户端证书，或邮箱验证码自助注册。宽屏左侧为工业走廊主视觉与悬浮数据模块；手机等窄屏只保留简洁背景，不加载立体场景。

**工作台**  
与 Agent 多轮对话，查看执行过程，对工具调用做批准或拒绝，必要时暂停、继续或取消任务。输入区旁展示本会话轮次 / 步数 / 输出速度与累计 Token、缓存命中；悬停可查看模型用时、工具用时、TTFT、TPS 与估算费用。侧栏可折叠，支持中英文与明暗主题。

**文件与文档**  
上传附件、浏览产出文件；Word / PPT 在右侧面板按页预览，再下载到本地。

**管理入口**（依权限显示）  
用户与角色、登录设备、我的证书与证书审批、模型配置、用量仪表盘（按天 Tokens / 估算费用）等。列表筛选统一为扁平 `filter-toolbar`（左侧放大镜搜索 + 下拉/按钮），不再套筛选卡片；证书管理按用户聚合分页。
